本輪先收集問題，不要求玩家刻意追求指定通關時間。

- 三種變身與各自技能、裝備外型。
- 五個封鎖點各一批敵人；原第三場改為無封鎖的階梯收集街段。

- 觸控多指輸入、聲音設定、路燈存檔與 BOSS 重試。

## 本輪重點

1. 手機橫向／直向按鍵是否遮擋角色，能否同時移動、跳躍、攻擊。
2. 是否存在無法跳上的平台、卡牆、穿台或落地不穩。
3. 普通敵人節奏是否拖沓；BOSS 預警、傷害與反擊空檔是否清楚。
4. 音樂循環與街區／BOSS／重逢轉場是否突兀；音效是否刺耳或蓋過配樂。
5. 變身是否能一眼辨認，跑跳時裝備位置是否自然。
6. 死亡重試、重新整理續玩，以及通關後重開是否正常。
