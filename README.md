# 柯基奇旅 · 黃昏麵包街

基於第一版柯基動畫素材的 2D 橫版動作遊戲。瀏覽器直接遊玩，支援鍵盤、觸控及手柄。

## 目前版本 · v0.2

- 單關街區與三階段 BOSS、重逢結局；BOSS 血量 1,200，較首版減少 62.5%。
- 麵包騎士、火花柯基、疾風柯基三種道具變身及可辨識裝備。
- 強制戰鬥由六場減為五場，每個封鎖點只出一批敵人；普通跳躍可逐階登台，疾風另有二段跳。
- 箱堆、間歇噴氣、錯落棚架和高低路線融入連續街區，散兵由 21 隻減為 10 隻；無額外小挑戰或收集目標。
- 三首使用者提供的音樂、音量設定、場景轉場和循環。
- 路燈存檔、死亡重試、悠閒模式。

## 操作

方向鍵 / AD 移動；空白鍵跳躍；J 攻擊；K 閃避；L 技能；Q 變身；E 互動；Esc 暫停。

## Cloudflare Pages

連接此 GitHub 倉庫，production branch 選 `main`，framework 選 `None`，build command 填 `node scripts/build-assets.mjs`，build output directory 填 `dist`。無需環境變數或後端。

遊戲部署內容位於 `dist/`。不要將 `.openai` 或其他平台憑證加入本倉庫。

## 回報問題

請使用 Issues 的「試玩問題」範本，附設備、瀏覽器、遊戲區域、重現步驟、預期結果與截圖／錄影。優先關注觸控多指操作、跳躍落台、BOSS 預警與音樂循環。

## 驗證與限制

已執行核心流程模擬、30/60 FPS 共 84 次平台落台測試、五個封鎖點單批出怪測試，以及地磚連續性與觸控輸入測試。新版另驗證舊存檔、徽章開門、BOSS 重試、箱子碰撞／破箱及噴氣通行。尚未完成新版真實手機與多人實機試玩；通關時間以實測為準。
